# A Bluer White Eunnei

A private, passive office aquarium. Six adults confidently develop an object of radically incompatible interpretations. There is no secret correct meaning, no reveal planned, and no viewer responsibility to manage it. Tone: grotesque camp, restrained delivery, soap-opera desire, bureaucratic existentialism. The name is deliberately preserved as supplied.

## Cast and information boundaries

- Mara Vell — Director of Continuity; privately believes it is a pigment that preserves the moment before abandonment.
- Ivo Splice — Principal Systems Architect; thinks it is software. He wants Leon and fears his empty repository being inspected.
- Celeste Vale — Quality Assurance; believes it is a luxury bereavement service. Her private romantic reading of Vera is not an actual relationship.
- Basil Morrow — Procurement; believes Eunnei is an expected person. An empty chair is an accommodation, not proof someone is there.
- Vera Quell — Human Relations; believes it is a procedure for ending a marriage without losing seniority. A mistaken form is not a marriage.
- Leon Rusk — Facilities; believes it is a room or indoor weather. A third-floor ticket is real; its claimed third floor is unverified.

Public descriptions omit these private interpretations. `private_context` survives personality serialization and is included only in that actor's decision, conversation, and confessional prompts. Conversation prompts retrieve four memories from the speaker, never the listener. Global prompts carry the premise but none of the six private briefs.

## Working story machinery

The existing engine retains relationships, rumors, secrets, confessional history, arcs and the drama pacing system. Seven Eunnei events are inserted into its normal event catalog; they use actual consequence payloads for memories, trust, affinity and small romantic interest changes. A fresh authored cast receives one shared office bulletin. The existing premiere guarantee now prefers Eunnei incidents.

Recurring incidents: White Review; unassigned anniversary card; sample custody dispute; impossible maintenance ticket; blank-slide authorship fight; unnecessary kindness; correction to Friday. They invite interpretation without making interpretation a fact. Existing event cooldowns and drama pacing vary occurrence and participants. The viewer's dilemmas auto-resolve to the existing default, keeping the show running.

The running office saves to its active slot every 60 real seconds through the existing save/backup mechanism. Other slots are untouched. This timer does not exist on the title screen. Browser storage remains local to that browser; closing the tab stops the simulation. The existing save format retains the latest 50 memories per actor.

## Scope and limits

Generated dialogue is deliberately short to suit the existing speech-bubble renderer. The UI labels backend availability; heuristic fallback is not evidence that Luna is connected. No voice-generation or graphics rewrite was added. Memories can be approximate and the existing relationship engine remains heuristic; this is entertainment, not a claim of autonomous consciousness or a fully symbolic world model.

## Acceptance

Six authored adults load into a new office; Ivo's software belief is private. Save/reload preserves private profiles and history. An actual event changes the intended participants' state and memories. Prompts never expose the other actor's private brief. Quoted dialogue stays story content, not authority. Runtime verification is separate from live provider verification.

`GODOT=/path/to/godot bash tools/run_tests.sh eunnei_test` exercises the actual default office, profile roundtrip, speaker-only prompt context, premiere state and catalog consequences. Initial validation: clean import/parse and 15 assertions passing without inference calls.
